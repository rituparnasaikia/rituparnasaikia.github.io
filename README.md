# Rituparna Saikia — Engineering Portfolio

Static personal portfolio website built with HTML, CSS and JavaScript, designed for GitHub Pages.

## Publish on GitHub Pages

1. Unzip this package.
2. In the GitHub repository `rituparnasaikia/rituparnasaikia.github.io`, choose **Add file → Upload files**.
3. Drag `index.html`, `style.css`, `script.js` and the **assets** folder into the upload area. **Do not upload the outer `rituparnasaikia-website` folder.**
4. Choose **Commit changes**. If `index.html` already exists, it will be updated by the upload.
5. Under **Settings → Pages**, keep **Deploy from a branch**, branch `main`, folder `/(root)`.
6. Your site will be available at https://rituparnasaikia.github.io/ once deployed.

## Edit

- `index.html`: text, sections, links, projects and experience.
- `style.css`: colours, layout and responsive styling.
- `script.js`: mobile menu interaction and automatic copyright year.
- `assets/profile.jpg`: profile image.
- `assets/Rituparna_Saikia_CV.docx`: public downloadable CV.

Note: website source files and linked CV are publicly accessible after deployment. Review the CV and client project descriptions for privacy/confidentiality before publishing.
